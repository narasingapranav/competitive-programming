## 📝 Summary

Determine if an array of n integers can be sorted in non-decreasing order by repeatedly reversing subarrays of length at most k.

## 🔍 Key Observation

If k >= 2, we can swap any two adjacent elements (reversing a subarray of length 2) to sort any arbitrary array; if k = 1, no elements can change positions, so the array must already be sorted.
