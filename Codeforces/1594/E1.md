## 📝 Summary

Count the number of valid colorings of a perfect binary tree of depth $k$ using six colors, where adjacent nodes cannot share the same or opposite color.

## 🔍 Key Observation

The root node can be colored in 6 ways, while each of the remaining $2^k - 2$ nodes in the tree has exactly 4 valid color choices determined by its parent's color.

## ⚙️ Algorithm

**Combinatorics**

## ⏱️ Complexity

| Time | Space |
|:--:|:--:|
| `O(k)` | `O(1)` |

## 🏷️ Tags

`combinatorics` `math` `trees`

<details>
<summary>💻 View solution</summary>

```python
n=int(input())
MOD=10**9+7
res=1
for _ in range(n-1):
    res=(res*4)%MOD
    res=(res*res)%MOD
print((6*res)%MOD)
```
